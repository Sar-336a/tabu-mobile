# Tabu Mobil (React Native / Expo)

Bu klasör, **Tabu Mobil Pro** oyununun saf React Native (TypeScript) ile yazılmış eksiksiz mobil versiyonudur.

## 📱 Telefonunuzda Çalıştırma Adımları

Telefonunuz yanınızda olduğunda sadece 2 adımda test edebilirsiniz:

1. **Bağımlılıkları Yükleyin:**
   ```bash
   cd react-native-tabu
   npm install
   ```

2. **Uygulamayı Başlatın:**
   ```bash
   npx expo start
   ```

3. **Telefonunuzdan Açın:**
   - Telefonunuza **Expo Go** (App Store veya Google Play) uygulamasını indirin.
   - Terminalde çıkan **QR Kodu** telefonunuzun kamerasıyla veya Expo Go ile okutun.
   - Uygulama saniyeler içinde telefonunuzda canlı olarak açılacaktır!
